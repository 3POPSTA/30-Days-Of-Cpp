## The C++ Core Guidelines: Key Rules
Authored by **Bjarne Stroustrup** and **Herb Sutter**:
1. **P.1: Express ideas directly in code**: Let compilers and static analyzers check your intent.
2. **R.1: Manage resources automatically using RAII**: Never use raw `new` and `delete` in modern business logic.
3. **ES.20: Always initialize an object**: Never leave variables uninitialized.
4. **F.16: For "in" parameters, pass cheap-to-copy types by value and others by reference to const**.
5. **C.21: If you define or `=delete` any copy, move, or destructor function, define or `=delete` them all (Rule of 5)**.
6. **Con.1: By default, make objects immutable (`const`)**.

## Essential Tooling & Static Analysis
- **Clang-Tidy**: Linter detecting bug patterns, performance inefficiencies, and readability violations.
- **Compiler Explorer (Godbolt.org)**: Interactive inspection of assembly output generated by GCC, Clang, and MSVC.
- **Valgrind / AddressSanitizer**: Memory leak detection and memory safety auditing.
- **CMake / Meson**: Standard industrial cross-platform build automation.

## 🛠️ Environment Setup & Toolchains

### 1. Windows (MSYS2 UCRT64 / MinGW-w64)
1. Install [MSYS2](https://www.msys2.org/).
2. In the MSYS2 UCRT64 shell, install the GCC toolchain and build tools:
   ```bash
   pacman -S mingw-w64-ucrt-x86_64-gcc mingw-w64-ucrt-x86_64-gdb mingw-w64-ucrt-x86_64-cmake
   ```
3. Add `C:\msys64\ucrt64\bin` to your Windows Environment `PATH`.
4. Open PowerShell and verify:
   ```powershell
   g++ --version
   ```

### 2. Linux (Ubuntu / Debian / Fedora)
```bash
# Ubuntu / Debian
sudo apt update && sudo apt install build-essential gdb cmake clang

# Fedora / Red Hat
sudo dnf install gcc-c++ gdb cmake clang
```

### 3. macOS (Apple Clang / Homebrew GCC)
```bash
xcode-select --install
brew install gcc cmake
```

## 🚀 How to Build and Run

### Option A: Compiling Individual Days via `g++`
Every `.cpp` file in this repository is completely standalone and ready to compile directly:

```bash
# Example: Day 01 Hello World
g++ -std=c++20 -Wall -Wextra 01_Day_Introduction/helloworld.cpp -o helloworld
./helloworld

# Example: Day 12 Multi-File
g++ -std=c++20 -Wall -Wextra 12_Day_Headers_and_namespaces/main.cpp 12_Day_Headers_and_namespaces/math_utils.cpp -o multi_file
./multi_file

# Example: Day 27 Multithreading
g++ -std=c++20 -Wall -Wextra 27_Day_Concurrency_and_multithreading/concurrency.cpp -o concurrency -pthread
./concurrency
```

### Option B: Building All 30 Days via CMake
A root `CMakeLists.txt` is provided to build the entire suite in one command:

```bash
# 1. Configure the build directory
cmake -B build -S .

# 2. Compile all targets
cmake --build build

# 3. Run any day's executable from build/
./build/day01
./build/day25
./build/day29
./build/day30
```

## 📘 Day 1: Introduction to C++

### What is C++?
C++ was designed by **Bjarne Stroustrup** in 1979 at Bell Labs as an extension of the C language. Over 40+ years of evolution, C++ has become the industry standard for high-performance computing, systems engineering, game development, embedded devices, and real-time mission-critical applications.

### Key Tenets of Modern C++
1. **Zero-Overhead Principle**: What you don't use, you don't pay for. What you do use, you couldn't hand-code any better.
2. **Deterministic Resource Management (RAII)**: Memory, locks, and file descriptors are acquired during initialization and cleaned up automatically upon exiting scope.
3. **Type Safety & Expressiveness**: Rich compile-time type checking with `constexpr`, templates, and concepts prevents bugs before your code ever runs.

### Hello World Explained Line-by-Line
```cpp
#include <iostream> // 1. Preprocessor directive to include I/O Stream declarations

int main() {         // 2. Program entrypoint returning integer exit status code
    std::cout << "Hello, World! Welcome to 30 Days of Modern C++!\\n"; // 3. Output
    return 0;        // 4. Return status 0 indicates success to the operating system
}
```

- `#include <iostream>`: Grants access to the standard input/output stream objects: `std::cout`, `std::cin`, and `std::cerr`.
- `std::cout`: Standard character output stream connected to terminal output.
- `<<`: Stream insertion operator. Chained to output multiple values.
- `'\\n'`: Newline character. Prefer `'\\n'` over `std::endl` in high-performance logging, as `std::endl` forces an expensive buffer flush every call.
- `return 0;`: Standard UNIX/Windows convention where exit code 0 signifies successful execution.

## 🏆 C++ Core Guidelines Philosophy
Throughout this challenge, keep the fundamental guidelines in mind:
- Prefer `std::vector` and `std::string` over raw C-arrays and pointers.
- Make variables `const` by default unless mutation is required.
- Pass small primitive types by value; pass non-trivial objects by `const &` (const reference).
- Use `std::unique_ptr` and `std::shared_ptr` to manage heap lifetimes automatically.
- Let algorithms from `<algorithm>` replace manual indexing loops.
